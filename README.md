# PBP💬

메신저처럼 가볍게 쓰는 **PbP(Play-by-Post) TRPG 세션 채팅방**입니다.
Firebase 무료 요금제로 누구나 자기 사이트를 직접 만들어 쓸 수 있습니다.

> 비상업 개인 프로젝트입니다. 특정 게임 회사와 관계가 없으며, 룰북 내용은 들어 있지 않습니다.
> AI의 도움을 받아 만든 코드이며, 있는 그대로(MIT 라이선스) 제공됩니다.

## 주요 기능

- 세션마다 방 만들기, 6자리 방 코드로 초대, 방마다 다른 닉네임
- 캐릭터 대사(인장·색), GM 서술·판정 안내·장면 구분선
- d100 판정(보너스·페널티 주사위, 성공 단계), 일반 주사위, 비밀 굴림, 귓속말
- 캐릭터 시트(상태·특성치·판정 목록), 시트 공개 범위, 다른 참여자에게 캐릭터 넘기기
- 핸드아웃(전체/특정인), 진행 요약, 장면 목록, 이미지, BGM 링크
- 접속 중·입력 중 표시, 안 읽은 표시, 알림음, (선택) 사이트를 꺼 둬도 오는 푸시 알림
- 굵게 `**글자**`, 연하고 작게 `((글자))`, 짧은 가름선 `---`, GM 서술 앞 `*`로 일반 글씨
- HTML 대화 기록 내려받기, 코코포리아·롤20 로그 가져오기
- 입장 비밀번호로 아는 사람만 가입, 방장(GM)의 참여자 내보내기
- 웜/쿨 화면 색감, 개인·방별 메인 컬러, 다크 모드

## 설치

### 준비물
- Google 계정, [Node.js](https://nodejs.org) LTS
- 터미널에서 Firebase 도구 설치: `npm install -g firebase-tools` (맥은 앞에 `sudo`)

### 1. Firebase 프로젝트 만들기
1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만듭니다.
2. **Authentication** → 시작하기 → **이메일/비밀번호**, (원하면) **Google** 로그인을 켭니다.
3. **Firestore Database** → 데이터베이스 만들기 (위치는 가까운 지역, 예: `asia-northeast3` 서울).
4. 프로젝트 설정 → **내 앱** → 웹 앱(`</>`) 추가 → 나오는 설정값을 복사합니다.

### 2. 설정값 넣기
- `public/firebase-config.js` — 1-4에서 복사한 값을 넣습니다.
- `firestore.rules` — 맨 위 `adminEmail()`의 `YOUR_EMAIL@example.com`을 관리자 이메일로 바꿉니다. (이 파일은 사이트에 공개되지 않습니다)
- `.firebaserc` — `YOUR_PROJECT_ID`를 프로젝트 ID로 바꿉니다.

### 3. 배포
```
firebase login
firebase deploy --only hosting,firestore
```
`https://프로젝트ID.web.app` 주소가 나오면 완성입니다.

### 4. 처음 할 일
관리자 이메일로 가입·로그인한 뒤, 로비의 **입장 비밀번호**를 정하세요.
다른 사람은 가입 후 이 비밀번호를 한 번 입력해야 들어올 수 있습니다. (12자 이상 권장)

## (선택) 푸시 알림

사이트를 꺼 둬도 새 메시지가 오면 알림을 받으려면 서버 기능이 필요합니다.

1. Firebase 요금제를 **Blaze**로 바꿉니다. (소규모 사용은 대부분 무료 사용량 안에서 끝납니다. **예산 알림을 꼭 걸어 두세요.**)
2. 프로젝트 설정 → **클라우드 메시징** → 웹 푸시 인증서 → **키 쌍 생성** → `firebase-config.js`의 `vapidKey`에 넣습니다.
3. 배포:
   ```
   cd functions && npm install && cd ..
   firebase deploy
   ```
4. 사이트의 **푸시 알림 받기** 버튼을 기기마다 누릅니다. 아이폰은 Safari → 공유 → **홈 화면에 추가** 후 그 앱에서 켭니다.

알림 내용은 "새 메시지가 도착했습니다." 한 줄이며, 방 이름·보낸 사람·대사는 담기지 않습니다.

## 업데이트할 때
`public/index.html` 등을 고친 뒤 `firebase deploy` 하면 됩니다.
Firebase SDK를 새 버전으로 묶고 싶을 때만 `build` 폴더에서 `npm install && npm run build`를 실행합니다.

## 보안 메모

- 데이터 접근은 `firestore.rules`가 막습니다. 귓속말·비밀 굴림·비공개 시트·전용 핸드아웃은 받을 사람만 읽을 수 있습니다.
- 서술·판정 안내·장면은 GM만, 캐릭터 대사는 그 캐릭터를 쓰는 사람만 올릴 수 있고, 주사위 결과 메시지는 수정할 수 없습니다.
- **한계:** 주사위는 각자의 브라우저에서 굴립니다. 개발자 도구를 다룰 줄 아는 참여자가 처음부터 가짜 결과를 올리는 것까지는 막지 못합니다. 믿을 수 있는 사람끼리 쓰는 도구로 생각해 주세요.
- 관리자 이메일은 공개되는 `firebase-config.js`가 아니라 `firestore.rules`에만 적습니다.
- `firebase-config.js`의 값은 원래 공개되는 값이지만, 저장소에 올릴 때는 **자기 프로젝트 값을 넣은 채로 커밋하지 마세요.**
